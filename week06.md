### e) Referrer

For packet 10, there is no `Referer` header in the HTTP request.

Therefore, the request does not provide a referrer value to the server. A referrer normally identifies the previous web page that caused the browser to request the current resource.

Web servers can use referrer information to understand where a request came from, such as which page contained a link to the requested resource.

The HTTP request for `myStyles.css` in packet 16 does contain a Referer:

`http://192.168.56.2/12327424.html`

This identifies the newly created HTML page as the page that requested the CSS file.

### i) Acknowledgements

TCP acknowledgements are used to confirm that data has been received.

For example, packet 9 is an ACK that completes the TCP three-way handshake before the HTTP request in packet 10.

There are also acknowledgements after HTTP data is exchanged. For example, packet 11 acknowledges data sent in packet 10.

An acknowledgement is normally sent after a TCP segment containing data has been received successfully. This allows TCP to provide reliable communication and detect missing data.
